# bounty.blink.sv

Source of https://bounty.blink.sv — Blink's public page following the coins of the 19 September 2026 attacker.

- Every address, transaction and channel listed is checked against the Bitcoin blockchain when the page is built.
- `data/` holds the same data the page shows (`indicators.csv`, `timeline.json`, `flows.json`, `holdings.json`).
- `timestamps/` holds a signed manifest per update with an OpenTimestamps proof.

Leads and reports go privately to bounty@blinkbtc.com with [BOUNTY] in the subject. Corrections to
bounty@blinkbtc.com with [CORRECTION] in the subject. Bounty terms: https://www.blink.sv/en/bounty-terms
